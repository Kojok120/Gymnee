■ レビュー用ノート（コピペ）
----------------------------------------------------------
Gymnee はジム通いの記録・継続・共有アプリです。確認のポイント:

1) サインイン: Sign in with Apple、または「名前を入力して始める」でローカル利用可。
2) ワークアウト記録: 「記録」タブから種目を追加し、重量・レップを入力。
3) アプリ内課金（非消耗型のみ）: キャラクターの見た目（配色・髪型・アクセサリー）と
   ペットを販売しています。いずれも**見た目だけ**で、機能・ゲーム進行・記録の内容には
   一切影響しません。自動更新サブスクリプションと消耗型アイテムはありません。
   - 購入する場所: 「育成」タブ → 画面下部の「見た目」ボタン → 色 / 髪型 / アクセ / ペット の各タブ
   - 購入を復元する場所: 「その他」タブ → 設定 → 購入 → 「購入を復元」
     （「見た目」シートの下部にも同じ復元ボタンがあります）
4) ショップ（「その他」タブ → ショップ）はアフィリエイト方式です。商品リンクは提携先
   （楽天市場・iHerb 等）の外部サイトへ遷移する広告で、物理商品のみを扱います。
   各掲載箇所に「広告」と明示しています（景品表示法のステルスマーケティング規制に対応）。
5) HealthKit: 体重・体組成の読み書きに使用。広告利用や第三者提供は行いません。
6) 位置情報: 使用していません（1.3.0 でジムのチェックイン機能ごと撤去済み）。

アカウント削除はアプリ内（設定 → すべてのデータを削除）で可能です。

----------------------------------------------------------
カメラ      : 進捗写真の撮影

HealthKit   : 体重・体組成の読込、ワークアウトの書き戻し
通知        : リマインド・自己ベスト通知等
