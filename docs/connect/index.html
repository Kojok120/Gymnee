Gymnee を、アプリの外へ

いつもの LINE や、Claude・ChatGPT に話しかけるだけで、自分の記録をもとに記録・ふりかえり・メニュー作りができます。仲間の Slack・Discord に記録を流したり、自分でスクリプトを書いたりもできます。

いちばん手軽

LINE にいるコーチ

話しかけるだけで記録とコーチ。毎朝のメニューも届きます。アプリのボタン 1 つでつながります。

 AI

Claude・ChatGPT につなぐ

URL を 1 つ足して、iPhone の Gymnee で承認するだけ。「今週のふりかえり」もボタン 1 つ。

 チーム

Slack・Discord にお知らせ

追加ボタンでチャンネルを選ぶだけ。記録を終えたときと、月曜の朝に先週のふりかえりを流します。

 開発者

API と API キー

記録を読む・足す REST API。Claude Code やスクリプトから使えます。

できること・できないこと

できる記録・自己ベスト・体重（アプリで記録した分）・パーティの状況を読む
ワークアウトの記録を足す（権限を付けたときだけ）
アプリのコーチ画面にメニューを提案する（権限を付けたときだけ）
できない記録を消す・直す（アプリだけで行います）
投稿・フォロー・ほかの人のデータを見る
アプリの計画を勝手に書き換える（提案を取り込むかはアプリで決めます）

安心して使えるように

  • 承認はあなたの iPhone で。つなぐときは、ブラウザと Gymnee アプリに同じ番号が出ます。見比べてから承認してください。
  • 渡す権限を選べます。「読むだけ」にもできます。
  • いつでも解除できます。アプリの その他 > 連携 から。
  • パスワードや Apple ID の情報、ヘルスケア（HealthKit）から取り込んだデータは、つないだ AI には渡りません。
  • くわしくはプライバシーポリシーの「外部連携」をご覧ください。

はじめる前に

  • Gymnee にサインインしている必要があります（設定 > アカウント）。
  • AI や API が読むのは、サーバーに同期された記録です。オフラインで記録した分は、通信できたときに反映されます。
  • 外から足した記録は、アプリを開くと同期されて表示されます。
