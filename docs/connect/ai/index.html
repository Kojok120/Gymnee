Gymnee を AI につなぐ

Claude や ChatGPT が、あなたの記録を読んで答えられるようになります。「今週どうだった？」「来週のメニューを組んで」と話しかけるだけです。

3 ステップ

  1. この URL をコピー（アプリの その他 > 連携 にも出ています）
    https://api.gymnee.app/mcp
  2. AI のアプリに足す。下の「アプリごとの場所」を見て、コネクタ（MCP サーバー）の追加の画面に貼ります。
  3. iPhone の Gymnee で承認。ブラウザに番号と QR コードが出ます。iPhone のカメラで読み取ると Gymnee が開くので、同じ番号か確かめて「承認する」を押します。

承認の画面で、渡す権限を選べます。「記録を足す」「メニューを提案する」を外せば、読むだけになります。

アプリごとの場所

画面の名前は、それぞれのアプリの更新で変わることがあります。

Claude（Web・デスクトップ・スマホ）

設定の「コネクタ」から、カスタムコネクタを追加します。名前は Gymnee、URL は上の URL です。追加したら「連携」を押すと承認の画面が開きます。

ChatGPT

設定の「アプリ」（コネクタ）から、カスタムの MCP サーバーを追加し、上の URL を貼ります。プランや設定によっては、開発者モードを有効にする必要があります。

Claude Code

claude mcp add --transport http gymnee https://api.gymnee.app/mcp

Claude Code の中で /mcp を開き、gymnee の認証を選ぶとブラウザに承認の画面が出ます。ブラウザを使わずにつなぐなら、アプリで作った API キーを渡します。

claude mcp add --transport http gymnee https://api.gymnee.app/mcp \
  --header "Authorization: Bearer gym_pat_xxxxxxxx"

そのほかの MCP クライアント（Cursor など）

リモートの MCP サーバー（Streamable HTTP）として登録します。OAuth に対応していれば URL だけ、対応していなければ API キーをヘッダーに付けます。

{
  "mcpServers": {
    "gymnee": {
      "url": "https://api.gymnee.app/mcp",
      "headers": { "Authorization": "Bearer gym_pat_xxxxxxxx" }
    }
  }
}

ボタンで使える問いかけ

つなぐと、AI のアプリの「/」や「＋」のメニューに次の 3 つが出ます。選ぶだけで、AI が必要な記録を読みに行きます。

今週のふりかえり今週を先週と比べて、よかったこと・偏り・来週の一手をまとめます。
来週のメニューを組む週の目標と最近の重量から来週のメニューを組み、よければアプリのコーチ画面に届けます。
伸び悩みを見る種目を 1 つ選ぶと、推定 1RM の推移から停滞しているかを見て、次の一手を出します。

話しかけ方のレシピ

  • 「先月の脚のトレーニングを週ごとの総量で表にして」
  • 「ベンチプレスの推定 1RM の推移を見て、次の 4 週の目安の重量を出して」
  • 「今日やったのはベンチ 60kg 10 回 3 セットと懸垂 8 回 3 セット。記録しておいて」
  • 「最近 1 週間休んでしまった。軽めのメニューを組んで、アプリに送って」
  • 「体重の推移と、トレーニングの回数を並べて見せて」

記録を足すときは、AI が中身を見せて確かめてから足します。同じ記録が二重にならないようにもなっています。足した記録は、アプリを開くと同期されます。

困ったとき

QR コードを読んでも Gymnee が開かない

iPhone で承認の画面を開いているなら「開かないときはこちら」を押してください。Gymnee が入っていないときは App Store から入れてから、もう一度読み取ります。

番号が違う・自分で始めた覚えがない

「拒否する」を押してください。他人が始めた接続を承認すると、その人があなたの記録を読めてしまいます。

あとから権限を足したい・減らしたい

アプリの その他 > 連携 で接続を解除し、つなぎ直して承認の画面で選び直してください。

AI が「記録が見つからない」と言う

サインインしているか、アプリを開いて同期できているかを確かめてください。AI が読むのはサーバーに同期された記録です。

やめたい

その他 > 連携 で解除すると、その AI はすぐに記録を読めなくなります。アカウントを消すと、連携もすべて消えます。
