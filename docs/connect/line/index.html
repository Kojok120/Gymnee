LINE にいるコーチ

いつもの LINE で、話しかけるだけ。やったことを送れば記録になり、迷ったらメニューを組んでくれます。アプリを開かない日も続けられます。

つなぎ方

  1. Gymnee アプリの その他 > 連携 で「LINE と連携」を押します。
  2. LINE が開き、Gymnee の公式アカウントのトークに「連携 123456」のような文字が入っています。そのまま送ってください。友だちに追加していなければ、先に追加します。
  3. 「連携しました」と返ってきたら完了です。アプリに戻ると「連携しています」になります。

コードは 10 分で切れます。切れたら、もう一度「LINE と連携」を押してください。

できること

記録する「ベンチプレス 60kg 10回 3セット」「懸垂 8回 3セット」「ランニング 5km 30分」のように送ると、内容を見せてから記録します。「記録する」を押したときだけ記録します。
今日のメニュー最近の記録から、今日のメニューを組みます。アプリのコーチ画面にも届くので、アプリで取り込むこともできます。やったら「やった！記録する」で記録に。
ふりかえり今週の回数・セット数・総量と、目標まであと何回かを返します。
相談する「肩が痛い」「時間がない」「やる気が出ない」など。記録を見て、無理のない一手を返します。医療の診断はしません。

画面の下のメニューのボタンを押すだけでも使えます。LINE で話した内容は、アプリのコーチの会話にも残ります。

通知の出し方

アプリの その他 > 連携 で選べます。届くのは 1 日に 1 通までで、その日もう記録していれば送りません。

途切れそうなときだけ最後の記録から 3 日たったときに、軽めに戻すための声かけ
毎日決めた時刻に、今週の回数と、今日どうするかの声かけ
毎日＋メニュー提案決めた時刻に、今日のメニューを組んで届ける
送らない通知は届かない（話しかければ答えます）

安心して使えるように

  • LINE に送った内容は、記録とコーチのためにだけ使います。グループやトークルームでは答えません（個人の記録を他の人に見せないため）。
  • LINE の名前やプロフィール写真は使いません。Gymnee が持つのは、つながっているかを見分ける LINE の ID だけです。
  • やめるときは、アプリの その他 > 連携 で「連携を解除」を押すか、LINE で公式アカウントをブロックしてください。ブロックすると連携も外れます。
  • くわしくはプライバシーポリシーの「外部連携」をご覧ください。
